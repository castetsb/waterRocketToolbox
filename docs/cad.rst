The CADs
========

The rocket parts are designed in FreeCAD. The CAD data is available in the
A-Design data folder.

Here below is the structure of the CAD data folder:

.. code-block:: text

   waterrockettoolbox/
   ├── A-Design Data
   │   ├── 1-Rocket
   │   │   ├── 1-PET bootle data => Regroup information about the PET bootle used to build water rockets
   │   │   ├── 2-Parts CAD => FreeCAD files of the rocket parts
   │   │   ├── 3-Drawings => FreeCAD drawaings of the rocket parts
   │   │   ├── 4-Assembly CAD => FreeCAD files of the rocket assembly
   │   │   └── 5-STL => STL files for 3D printing (Not systematically updated)
   │   ├── 2-Launcher
   │   │   ├── 1-Parts CAD  => FreeCAD files of the launcher parts
   │   │   ├── 2-Drawings => FreeCAD drawings of the launcher parts
   │   │   ├── 3-Assembly CAD => FreeCAD files of the launcher assembly
   │   │   └── 4-STL => STL files for 3D printing (Not systematically updated)
